Entry for the make.fun bounty [The GPS Swears It Was a Shortcut](https://make.fun/c/u-alven-the-gps-swears-it-was-a-shortcut-2cac21d9): the GPS's one-line excuse, in its own voice, for sending the driver down the wrong road.

## The line

> I turned you left at the Johnsons' wedding because the map said the lake was shorter, and it was, by three feet.

112 characters. First-person GPS, smug and defensive, blaming the map — a wedding and a lake, not the usual recalculating joke.

## How it works

`main.ts` (Node 22, no dependencies) writes the line to `/output/entry.txt` — plain text, no trailing newline, inside the 1–200 character gate.
